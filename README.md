# Sabor & Arte — Projeto Front-End

Projeto académico desenvolvido para a disciplina de Front-End.

## Funcionalidades
- Layout responsivo.
- Navegação semântica e suporte a teclado.
- Filtro de menu.
- Formulário de reserva com validação.
- Modo claro e modo escuro.
- Elementos ARIA, foco visível e skip link.

## Estrutura
- index.html
- styles.css
- script.js

## Execução
Abra index.html num navegador. Não são necessárias dependências externas.

## Deploy
O projeto pode ser publicado na Vercel através do repositório GitHub.
